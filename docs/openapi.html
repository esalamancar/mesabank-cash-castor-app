CashCastor API (0.1.0)

Download OpenAPI specification:

Erick Salamanca: easalamancar@siesa.com

API del MVP de CashCastor. Backend en Go + Gin, expuesto vía HTTPS con autenticación JWT Bearer. Además de los endpoints REST documentados aquí, la API expone un canal de tiempo real por WebSocket en wss://{host}/games/{code}/ws (ver 03-arquitectura.md). Nota sobre WebSocket: OpenAPI 3.1 no tiene soporte nativo para describir un canal WebSocket como una operación HTTP normal. El endpoint se documenta más abajo (tag tiempo-real) de forma descriptiva, usando la extensión x-websocket: true, únicamente con fines de referencia; no es una operación HTTP invocable con este contrato. Decisiones de alcance del MVP (PO, 2026-09-18): - El campo GameConfig.inflation se acepta y se persiste, pero no tiene ningún efecto funcional en el MVP (pendiente de POC, ver 07-historias-usuario.md, US-036 y US-201).

  • El arqueo de papel moneda (/games/{code}/cash-audit) solo puede ser declarado por el rol Banco.
  • /ranking es un leaderboard de mejores partidas individuales, sin acumulación por usuario.
  • Los espectadores no tienen acceso a /games/{code}/transactions.
